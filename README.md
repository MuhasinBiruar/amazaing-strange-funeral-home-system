## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create the environment files:

   - Copy `client/.env.example` to `client/.env`
   - Copy `server/.env.example` to `server/.env`

3. Update the environment variables as needed.

## Run the application

   ```bash
   npm install
   ```
